# 견적서·계약서 단가 비교

공급사마다 양식이 다른 견적서를 같은 틀로 옮겨 항목별 단가를 비교한다.

## 입력과 산출물

- 입력: 공급사별 견적서 또는 계약서 PDF (`data/`에 둔다)
- 산출물: `workbooks/quotation_comparison.xlsx` (시트 `raw`, `comparison`, `check`)

## 단계

| 순서 | 도구 | 하는 일 |
|---|---|---|
| 1 | `markitdown` | PDF를 Markdown으로 변환한다. 표가 깨진 쪽은 쪽수를 적어 둔다 |
| 2 | 모델 | 아래 스키마로 항목을 추출한다. 문서에 없는 값은 비워 두고 `확인 필요`로 표시한다 |
| 3 | `duckdb` | 추출 결과를 적재해 단위를 맞춘다(수량 단위, 부가세 포함 여부, 통화) |
| 4 | `excel` | `raw`에 원본 추출값, `comparison`에 공급사별 단가와 최저가 대비 차이, `check`에 확인 필요 항목을 쓴다 |
| 5 | `/redteam` | 비교 결론(어느 공급사가 싼가)에 대해 가장 치명적인 반론 하나를 받는다 |

## 추출 스키마

| 열 | 설명 |
|---|---|
| `supplier` | 공급사명 |
| `item` | 품목명(원문 표기 그대로) |
| `item_std` | 표준 품목명(비교용으로 맞춘 이름) |
| `spec` | 규격·사양 |
| `qty`, `unit` | 수량과 단위 |
| `unit_price`, `currency` | 단가와 통화 |
| `vat_included` | 부가세 포함 여부 |
| `source_page` | 원문 쪽수 |
| `basis` | `실측`, `가정`, `확인 필요` 중 하나 |

## 검증

- `raw` 시트에서 공급사별로 5행 이상을 뽑아 원문 쪽수와 직접 대조한다.
- 공급사별 합계가 견적서에 적힌 총액과 맞는지 확인한다. 맞지 않으면 누락 행이 있다는 뜻이다.
- `item_std`로 묶인 항목이 실제로 같은 사양인지 확인한다. 사양이 다르면 단가 차이는 가격 차이가 아니다.
- `basis`가 `가정`이나 `확인 필요`인 행은 결론에서 제외한 경우의 결과도 함께 적는다.
